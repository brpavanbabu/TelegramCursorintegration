# ⚡ Quick Start Guide - ON THE FLY!

Get up and running in **2 MINUTES** with **ONE COMMAND**!

---

## 🚀 The Fastest Way (One Command!)

```bash
# 1. Clone
git clone https://github.com/brpavanbabu/telegram-cursor-integration.git
cd telegram-cursor-integration

# 2. Install & Run (does EVERYTHING automatically)
node install.js
```

**That's it!** 🎉

The installer will:
- ✅ Check your system
- ✅ Install all dependencies
- ✅ Ask for your bot token (takes 20 seconds)
- ✅ Configure workspace
- ✅ Test connection
- ✅ Start the bot immediately

**No hassle. No manual steps. Just works!** ⚡

---

## 📱 Get Your Bot Token (20 Seconds)

While the dependencies install:

1. Open **Telegram**
2. Search: `@BotFather`
3. Send: `/newbot`
4. Give it a name (e.g., "My Cursor Bot")
5. Copy the **token** (looks like: `123456789:ABCdef...`)

Paste it when the installer asks! ✅

---

## 🎯 Test Your Bot

After installation completes:

1. **Find your bot** on Telegram (search for its name)
2. Send: `/start`
3. Send: `Build me a hello world app in Python`
4. **Watch Cursor open and execute!** 🎊

## 🆘 Troubleshooting

### Can't run `node install.js`?

**Fix:** Install Node.js first: https://nodejs.org/

### Bot not responding on Telegram?

**Fix:** Make sure the bot is running:
```bash
node telegram-cursor-bot.js
```

### Cursor not opening?

**Fix:** Make sure Cursor IDE is installed: https://cursor.sh/

---

## 🎓 What Happens During Install?

The `install.js` script:

1. ✅ **Checks Node.js** (makes sure you have it)
2. ✅ **Installs dependencies** (`npm install` automatically)
3. ✅ **Asks for bot token** (one-time setup)
4. ✅ **Sets workspace path** (where your projects go)
5. ✅ **Tests Telegram connection** (verifies it works)
6. ✅ **Checks for Cursor** (makes sure it's installed)
7. ✅ **Starts the bot** (you're ready to go!)

**Total time: ~2 minutes** (mostly waiting for npm to download packages)

---

## 🔄 Restart Bot Later

If you close the bot and want to restart:

**Simple way:**
```bash
node telegram-cursor-bot.js
```

**Windows way:**
```powershell
.\start-bot.ps1
```

**npm way:**
```bash
npm start
```
